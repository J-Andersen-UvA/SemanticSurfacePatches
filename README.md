# Semantic Surface Patches

This Unreal plugin owns reusable semantic surface-patch data and authoring tools. A patch identifies a meaningful region on paired meshes without depending on animation correction or collision solving.

## Modules

- `SemanticSurfacePatches`: runtime data assets and patch data.
- `SemanticSurfacePatchesEditor`: legacy import and future patch-authoring and visualization tools.

## Repository contents

Authored assets under `Content` are intentionally not ignored. Generated Unreal folders such as `Binaries`, `Intermediate`, and `Saved` are ignored.
